# Healthcare Claims Analytics Dashboard

### Power BI | SQL | Healthcare Data Analytics

## Project Overview

An interactive healthcare analytics project focused on understanding insurance claims, approval and denial rates, financial performance, and claim processing trends.

## Dashboard Preview

![Healthcare Claims Analytics Dashboard](Healthcare%20project%20dashboard.png)

## Key Performance Indicators

| Metric | Value |
|---|---|
| Total Claims | 10K |
| Total Claim Amount | $16.10M |
| Total Approved Amount | $10.52M |
| Approval Rate | 76.6% |
| Denial Rate | 15.6% |

## Dashboard Features

- Claims analysis by approval and denial status
- Financial analysis of claim amounts
- Insurance plan and diagnosis comparisons
- Claim processing time analysis
- Monthly claims trends
- Geographic claims analysis

## Tools & Technologies

- **Power BI:** Interactive dashboards and visualizations
- **SQL:** Healthcare claims analysis
- **CSV:** Source dataset
- **DAX:** Dashboard calculations

The dashboard provides a consolidated view of claims activity, helping identify financial patterns, claim status distributions, and operational trends.
